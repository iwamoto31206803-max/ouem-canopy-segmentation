# P1-1 offline preprocessing baseline

**Status: PARTIAL / real-data NOT VERIFIED.** No fine-tuning or official holdout/GT54 use.

- `binary_canopy_mask` accepts **semantic** class IDs, not raw panoptic segment IDs. The real dataset's panoptic decoder remains to be verified.
- `degrade_pair`: top-left crop 2048→2040, factor-5 block averaging RGB and canopy fraction, output 408×408, threshold >=0.5.
- All-zero/all-one GT is preserved; no source modification.
- `write_pair`: derived RGB, fraction NPY, mask and SHA-256 manifest.
- `validate_disjoint`: rejects train/validation overlap by oam_id.
